🍕 Project 1: FOMINS Foodtech Ecosystem (Monorepo)

Full-Stack Multi-App Architecture for Urban Workplace Dining & Quick Food Delivery

fomis-foodtech/
├── apps/
│   ├── customer-app/          # Native React Native (Expo) - Swiggy/EatSure/Swish Tier UI
│   ├── rider-app/             # Native React Native (Expo) - Fleet Partner App (Play Store Ready)
│   └── web-kds-admin/         # Next.js App Router - Tablet Kitchen Display System & Super Admin
└── packages/
    ├── shared-firebase/       # Centralized Firebase SDK, Firestore rules, schemas & shared hooks
    └── ui-tokens/             # Design tokens, color palettes (#E53E3E, #2D3748), typography

Problem & Vision: Urban professionals face a sharp tradeoff between speed (quick commerce snacks) and meal quality (fresh culinary dining). FOMINS bridges this gap by integrating a multi-brand cloud kitchen with a unified digital ecosystem.

Key Implementation: Built using a synchronized monorepo pattern where customer ordering, kitchen dispatch, and fleet delivery share identical TypeScript interfaces, Firestore schemas, and brand tokens. Includes a high-contrast tablet interface for chefs (Kitchen Display System - KDS) to mark food prep milestones (Queued ➔ Cooking ➔ Ready ➔ Dispatched).
